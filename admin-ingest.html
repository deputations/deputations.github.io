Readers flag problems on live vacancies. Open in the manager to fix the vacancy yourself, then mark the flag ✓ Valid (keep for the record) or Dismiss (invalid / hide). Sorted by endorsements.

Feedback

Messages sent from the Contact page “Send feedback” form. Each shows the page it’s about. Mark ✓ Resolved when handled, or Re-open to revisit.

Pending updates & duplicates

A re-upload that matches a live vacancy queues here as an update — Apply to enrich the live row with the new data. A re-upload that looks like the same post on a different date shows as a possible duplicate — Merge into existing (update the live row) or Create as new (keep both). Identical re-uploads are skipped automatically.
